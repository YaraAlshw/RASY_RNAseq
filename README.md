# RASY_RNAseq

This repository contains all the scripts used to analyze RNAseq data, conduct differential gene epression analysis, and GO enrichment analysis in <a href="https://link.springer.com/article/10.1186/s12864-026-12535-y"> Alshwairikh & Skelly 2025</a> 

This reporsitory is archived on <a href="https://zenodo.org/records/17674312">Zenodo</a>

Script to analyze RNAseq data was adopted from <a href="https://doi.org/10.1016/j.cbd.2024.101296">Vaziri et al. 2024</a>

Raw RNAseq data is available on NCBI under BioProject ID PRJNA1247543.
